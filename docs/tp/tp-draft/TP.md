# Travail pratique — Autocomplétion et structures de données

## Contexte général
Les systèmes d’autocomplétion et de prédiction de texte reposent sur des statistiques extraites de grandes quantités de données textuelles.
Dans ce travail pratique, vous allez concevoir la composante d’apprentissage d’un tel système, en mettant l’accent sur le choix et l’utilisation efficace de structures de données.

Ce projet ne vise pas à reproduire les performances des modèles modernes de traitement du langage naturel.
L’objectif est de comprendre comment des modèles simples, basés sur des statistiques locales, peuvent être implémentés efficacement.

## Objectifs pédagogiques
- Choisir des structures de données adaptées
- Analyser complexité temps/espace
- Implémenter des opérations de classement efficaces

## Description générale
Votre travail porte exclusivement sur la composante d’apprentissage et de prédiction.
Le prétraitement, le benchmark et l’interface CLI sont fournis.

Voir preprocessing.md et predictions.md pour les contrats précis.
